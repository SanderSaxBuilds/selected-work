Separate output-path check

An existing results folder stays untouched

After the clean run created its result folder, the same output path was tried again. ExportCheck refused it with process exit code 3. The three existing result files had the same paths, byte sizes, and SHA-256 hashes before and after the refusal.

Scope of this proof

What these runs establish

The output reflects only the exact sample rules shown above.

Decimal checks are exact

The sample requires a finite plain decimal, permits at most two digits after the point, and includes its negative and positive bounds. It does not infer a currency or reconcile totals.

Rejected rows remain available

Every row-level issue appears in row-errors.csv. Each issue record includes the complete source row as original_row_json, so rejected data is retained in the output.
