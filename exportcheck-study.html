CSV preflight, a command-line tool in Python

Check the CSVbefore it leaves.Keep the rows that fail.

ExportCheck reads one CSV against a small JSON rules file. Rows that pass go to clean.csv. Every rejected row goes to row-errors.csv with each reason and the full original row, so nothing quietly disappears. A summary.json keeps the counts.

$ python exportcheck.py --input orders.csv \
    --rules rules.json --output runs/orders

Where this stops

        
ExportCheck 1.0.0 has been tested on synthetic files only and has no customer use yet. The bench is a JavaScript port of the same checks, written so the tool can be tried without installing anything.

        
    
          
  • Amounts are checked as exact decimals within a range. It doesn't infer currency or reconcile totals.
    • 
          
  • It doesn't repair rows, guess delimiters or read Excel files.
    • 
          
  • It doesn't connect to an ERP or send the file anywhere.
    • 
        

      

      

        
What it needs

        
Python 3.10 or newer and nothing else. The standard library covers the CSV reading, decimal checks and file writing. Inputs up to 5,000,000 bytes and 10,000 rows by default, adjustable in the rules file.
