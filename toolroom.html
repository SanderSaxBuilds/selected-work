Before you start

Good questions.

Can I buy these tools here?

This is a storefront demonstration. The bag and demo checkout create local test orders only. No payment, real purchase, license grant or email delivery occurs.

What will I download?

The preview downloads are clearly labelled sample CSV or text files. Full product archives are not served by this demo.

Where does my library live?

In this browser on this device, when browser storage is available. Backup creates a portable JSON file. Restoring validates the file before changing the library. Private browser sessions and cleared storage can remove local data.

Does this connect to Etsy or another shop?

No. This independent demo does not connect to Etsy, Payhip or any payment provider. Production checkout and fulfillment need a separately configured service.
