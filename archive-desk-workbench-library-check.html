Try it

  1. Start the app. The overview shows how.
  2. Create a backup or import an existing Archive Desk ZIP.
  3. Select Check every backup below the saved library.
  4. Read the totals and every failed row. Download this report saves the same result as JSON. A check never starts a repair or a recovery.

Reading the result

Label, recorded and fresh fingerprint, status and reason. An empty library is never a pass.

History stays apart from the fresh check. Failures show Check failed.

No absolute paths. Read it before sharing.

Recovery stays separate

Recovery still runs through its own reviewed plan, which checks a new destination and the file list before you confirm.

  • Unencrypted Archive Desk ZIPs only.
  • Up to 500 files, 20 MiB per file, 50 MiB of source data and a 52 MiB ZIP.
  • Manual checks only, with no schedule or cloud sync.
