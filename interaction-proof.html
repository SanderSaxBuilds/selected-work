How it is built

Four SVG plates, blended with mix-blend-mode: multiply and stacked in 3D with translateZ. The loupe draws the dots on a canvas from the plate images. No libraries.

Dot angles

// d(x, y) is 0 to 1, read from the plate drawing
for (const [p, angle] of SCREENS) {
  const d = density[p];
  forEachCell(angle, cell, (x, y) => {
    const r = cell * Math.sqrt(d(x, y) / Math.PI);
    if (r > .15) dot(x, y, r, INK[p]); // multiply blend
  });
}
