CSS and SVG interaction study

One process graphic, three ways to explore it.

A flat input, process and result diagram that opens up into layers. Scroll down and the layers pull apart. Move the pointer over it and it tilts. The buttons and slider do the same job for anyone who'd rather click or use a keyboard.

How it's built

Three SVG drawings and one CSS variable.

Each layer is an ordinary SVG inside a tile. Depth is a CSS custom property fed into translateZ, and the stage's perspective does the rest. No canvas and no libraries, so the drawings stay editable as plain markup.

Scroll updates are batched to one per animation frame. Touching the slider or a button hands control to you until you scroll again.

An independent study by Alexandr Khrustalev. It's a CSS and SVG depth effect, not a Rive file or a 3D render.
