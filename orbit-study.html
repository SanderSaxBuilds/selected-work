WebGL interaction study

Three rings, one shared orbit.

A small 3D scene written straight against WebGL, with no libraries. Drag across it or turn it with the arrow keys. If you'd rather it kept still, it stops on request and falls back to a flat drawing when WebGL isn't available.

With the scene focused, the Arrow keys turn it, Space pauses and Home resets the view.

Loading the sceneDrag or use the arrow keys

How it's built

One ring, drawn three times.

The page builds a single torus of 9,216 vertices once and draws it three times with a different size, tilt and color. A short shader adds diffuse light, a specular highlight and a soft rim.

Respects the visitor

Motion is optional

If the device asks for reduced motion, the scene starts still. Rotation also pauses while the tab is hidden, so it doesn't burn battery in the background.

Works without WebGL

A drawing takes over

If WebGL is missing or the graphics context is lost, the canvas is hidden from view and from screen readers and a matching SVG drawing replaces it.

Keyboard and touch

No mouse needed

The scene is focusable and turns with the arrow keys. On touch screens a horizontal drag turns it and a vertical swipe still scrolls the page.
