Responsive interaction example, revision 1

Open index.html in a browser. The HTML, CSS and interaction source are editable. The included local jQuery dependency avoids needing a CDN connection.

This original example demonstrates responsive layout, a narrow-screen navigation menu, an expandable detail, required-input validation and safe text display. Form data is not sent or saved. It is an independent demonstration, not paid client work.

Original example source is shared for application review. The separately included jQuery library is distributed under the MIT license, see jquery-LICENSE.txt.

This example does not establish native Photoshop or InDesign editing, PHP, a backend service, a production migration or years of specialist experience.
