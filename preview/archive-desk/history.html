Start on Windows

  1. Download the Windows x64 ZIP and extract the whole folder.
  2. Open Try Demo.cmd to explore a fictional sample project in your browser.
  3. Stop the demo with Ctrl+C. Open Start Workbench.cmd and paste your project folder and a separate folder for the backup library.
  4. Leave the console window open while you use the app.

Nothing else to install. Keep the remembered folder settings private.

Or run the source

Node.js 24, no packages. Run in the ArchiveDeskWorkbench folder.

node server.mjs
# then open http://127.0.0.1:4330/

npm test

Your own folders, on one line:

node server.mjs --workspace "C:/Projects/site"
  --storage "D:/ProjectBackups/site" --port 4330

Run history: keep the result, return to the record

Every outcome is kept, even after a restart.

  1. 01

    Partial stays partial.

    Time, result per folder, and counts. A failed save is reported, not retried.

  2. 02

    Find the original run.

    By set, time or run ID. Nothing is purged automatically.

  3. 03

    Download the saved JSON.

    The stored bytes. A changed record must be refreshed first.

A record is not a fresh check

History shows the run as it happened. Use Check every backup for the current state.

Open current library entry jumps to the matching archive.

Reports drop absolute paths. Read the JSON before sharing.

Tested on Windows x64 only. It has not been tested on Windows on ARM, macOS or Linux.

Good to know

  • Imported ZIPs up to 52 MiB.
  • Unencrypted Archive Desk ZIPs only. No compressed or ZIP64 imports.
  • No timestamps, permissions or empty folders on recovery.
  • Credential files are skipped by name, not by content.
  • Manual runs, no schedule or sync. Close editors first.
  • Keep a second copy on another device.
