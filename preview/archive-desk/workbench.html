Try it

  1. Start the app from the Windows download or the source. The overview has both routes.
  2. Choose Run sample workflow to back up, compare and recover a fictional project in one pass.
  3. For your own work, keep the project and the backup library in separate folders. The browser only accepts paths inside the workspace you chose at startup.
node server.mjs --workspace "C:/Projects/site"
  --storage "D:/ProjectBackups/site" --port 4330

Type the command on one line. The library keeps backup records and recent activity across restarts.

A second copy still matters

The same drive will not survive its own failure. Keep a copy on another device.

Close editors while a backup runs. It is not an atomic snapshot.

Limits

  • Up to 500 files, 20 MiB per file and 50 MiB of source data.
  • The Archive Desk ZIP format only, not any ZIP you have.
  • Paths and contents are restored. Timestamps, permissions and empty folders are not.
  • Common credential and dependency names are left out by filename. That is not a scan of file contents.
