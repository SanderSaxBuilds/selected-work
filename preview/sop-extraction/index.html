Refusal codes

      
If a document does not fit the template, the tool stops with one of these 42 codes and writes nothing.

    

    

      
      
      42 codes
    

    

      

        
Input
Before anything is opened

        
    
          
  • INPUT_READ_FAILEDThe source file can't be read.CLI only
    • 
          
  • INPUT_SIZE_LIMITThe file is larger than 8 MiB.open a big file
    • 
        

      

      

        
ZIP package
Checked from the directory, before a member is read

        
    
          
  • ZIP_INVALIDNot a ZIP archive at all.open a non-ZIP file
    • 
          
  • ZIP_MEMBER_COUNT_LIMITMore than 256 members.
    • 
          
  • ZIP_DUPLICATE_MEMBERThe same member name appears twice.
    • 
          
  • ZIP_UNSAFE_MEMBERA name with a backslash, a colon, a leading slash or a dot segment.
    • 
          
  • ZIP_ENCRYPTED_MEMBERA member is encrypted.
    • 
          
  • ZIP_UNSUPPORTED_COMPRESSIONAnything other than stored or deflate.
    • 
          
  • ZIP_MEMBER_LIMITA member expands past 4 MiB, or past its own part limit.
    • 
          
  • ZIP_TOTAL_SIZE_LIMITAll members together expand past 16 MiB.
    • 
          
  • ZIP_COMPRESSION_RATIO_LIMITA member expands more than 250 times its compressed size.
    • 
          
  • UNSUPPORTED_PACKAGE_CONTENTMacros, ActiveX or embedded packages, by part name or content type.
    • 
          
  • ZIP_MEMBER_READ_FAILEDA required part fails to decompress or its checksum is wrong.
    • 
          
  • ZIP_SIZE_MISMATCHA part's bytes don't match the size the directory declared.
    •

Template
Paragraph by paragraph

        
    
          
  • TEMPLATE_MISSING_TITLEThe first non-empty paragraph isn't the title, or there is none.
    • 
          
  • TEMPLATE_EMPTY_TITLEThe title label has no text.
    • 
          
  • TEMPLATE_MULTILINE_TITLEThe title has a line break.
    • 
          
  • TEMPLATE_DUPLICATE_LABELA second title, safety notes or the same step number.
    • 
          
  • TEMPLATE_AMBIGUOUS_CONTENTAn unlabeled paragraph, or labels in the wrong order.
    • 
          
  • TEMPLATE_EMPTY_SAFETY_NOTESThe safety notes label has no text.
    • 
          
  • TEMPLATE_STEP_NUMBER_LIMITA step number longer than nine digits.
    • 
          
  • TEMPLATE_EMPTY_STEPA step label with no instruction.
    • 
          
  • TEMPLATE_NO_STEPSA title and no steps.
    • 
          
  • TEMPLATE_STEP_SEQUENCESteps that don't start at 1 or skip a number.
