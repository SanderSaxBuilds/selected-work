Stillwater Bottle product page

Open index.html on a static web server. The page keeps colour, capacity, engraving, price, stock, photo and the ?variant= link in step with every choice, including Back and Forward. The page itself takes on the tone of the chosen colour.

What it does:
- Four studio views per colour and size: front, lid off, cap and lip, and both sizes side by side. Thumbnails, arrow buttons, arrow keys and a horizontal swipe move between them.
- Zoom follows the pointer, or pans with the arrow keys while the Zoom button has focus.
- Optional engraving, up to 14 letters, previewed live on the front photo and priced at $6 a bottle. Engraved and plain bottles are separate lines in the bag.
- A size helper: drag the hours you are out and it works out the water and picks the bottle, with a button that selects it.
- When an option is sold out, one button switches to the nearest option that ships.
- A slim buy bar appears once the main Add button scrolls away.
- The bag holds items in memory for the current visit only, with quantity steppers and a meter toward the $50 free shipping line.

The Store QA study panel reproduces two common store bugs on purpose: a photo that stays on the previous option, and a photo address that returns a 404 so the fallback appears. These are demonstrations, not checkout or a live shop.

Fieldnote Goods, the product, prices, stock and variant IDs are fictional. The bottle renders are original SVG drawings made for this page. This is plain HTML, CSS and JavaScript. It does not establish Shopify theme or API compatibility, a client repair or customer acceptance.
