Variant gallery regression study

Open index.html on a static web server. The fictional bottle preview keeps color, capacity, price, availability, image and the variant link in sync.

The Study controls compare the working gallery with an intentionally stale image. A separate missing-image fixture requests a nonexistent image and shows the fallback. These are demonstrations, not checkout or a live shop.

The product, prices, inventory and variant IDs are synthetic. The SVG artwork is original. This is ordinary HTML, CSS and JavaScript. It does not establish Shopify theme or API compatibility, a client repair or customer acceptance.
