      How a duplicate is caught

      The lookup and the save run in one transaction, so 24 copies at once give 1 saved and 23 duplicates.

      How two copies are compared

      The keys are sorted and the spaces removed, then the text is hashed. Different spacing counts as the same update. A different value does not.

      Older updates

      An older update is saved too, but the shipment keeps the newest status.

      Limits

      A study with made-up shipments, not a production service.

      • One kind of event and one local SQLite database.
      • A new signing key is made each time the service starts.
      • The five-minute window and the ordering rule are choices for this study.
      • It is not connected to a real courier, and it does not make other side effects run exactly once.

      For a real project

      First I reproduce the failure from one anonymized event. Then we agree the ID, retry and ordering rules before changing storage.
