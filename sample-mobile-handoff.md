# Clearline interface refinement proof

Independent mobile interface with fictional expense data, not the buyer's actual app. Existing layout and working filters are retained and extended.

## New work

Review, approval and correction states. A decision can be undone. Status filters include correction requests. Reset restores the original sample. Focus moves to the new screen and decision feedback, Escape returns from detail to activity. Keyboard controls and live feedback are available. State is intentionally in-memory, no storage, account, backend or payments.

## Editable sources and UI specifications

Source: index.html. Built-in Arial font, no fonts or images fetched. Background #edf1ee, primary #245c42, ink #152c37, focus #e39d33. Spacing follows 8/12/16/24 units. Card radius 15 to20px. Phone layout targets 390px width, desktop presents a contained mobile proof alongside its explanation.

Views: overview, activity, expense details. States: all/to-review/approved/correction filters, search match, no results, awaiting decision, approved, correction requested, undone and reset. Fictional items total USD1242. Decisions change counts and status, never total spending or money movement.
