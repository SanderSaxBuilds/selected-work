Claude Mail privacy policy

Last updated 10 November 2026.

Who this covers

Claude Mail is a personal tool used only by its owner, with Gmail accounts the owner controls. It has no other users.

What it accesses

After the owner signs in with Google, Claude Mail uses the Gmail API to read, search, draft and send messages in that account. It asks for no other Google data.

Where the data goes

Claude Mail runs on the owner's own computer. Sign-in tokens are stored only on that computer. There is no Claude Mail server and no database. Message content is read on that computer and by the owner's AI assistant service, at the owner's direction, to carry out the owner's own mail tasks.

What it never does

Claude Mail does not sell Gmail data, does not share it with advertisers or data brokers, does not use it for advertising, and does not give it to anyone other than the owner and the services the owner uses to handle the owner's own mail.

Google API data

Claude Mail's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the token files on the owner's computer removes the stored sign-in.

Contact

Questions go to the developer through github.com/SanderSaxBuilds.
